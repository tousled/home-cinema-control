# Support

## Before opening an issue

1. Check the relevant installation and configuration section.
2. Confirm the installed HCC version and Docker image tag.
3. Reproduce the problem with a minimal configuration when possible.
4. Export a redacted diagnostic summary.

Do not include passwords, access tokens, webhook IDs, private keys, full private paths, server credentials, or complete configuration files.

## Issues

Open a public issue for a reproducible bug, a documentation problem, or a clearly described product proposal. Include:

- HCC version;
- Emby or Jellyfin version;
- OPPO/Chinoppo model and firmware;
- relevant TV/AV models;
- expected and actual behavior;
- the redacted diagnostic information.

For general questions, describe the room topology without publishing private network addresses or credentials.
