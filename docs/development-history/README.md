# Development history

Home Cinema Control was developed publicly for many months before product
development moved to a private source repository. The historical project
included a public issue tracker, 88 pull requests, 85 merged pull requests,
3 closed unmerged pull requests, multiple release candidates, and the version
history recorded in [`RELEASE_HISTORY.md`](../../RELEASE_HISTORY.md).

This repository preserves the public product and release history without
publishing the HCC source code, internal patches, or private development
workflows. Historical pull requests remain in the private source or historical
repository and are not recreated here as public pull requests.

## Historical stages

- `0.1.0`–`0.9.1`: initial product development, installation flow, playback
  control, media-server integration, and incremental reliability work.
- `1.0.0`–`1.0.5`: first stable product line and configuration/authentication
  improvements documented in the historical changelog.
- `1.1.x`: provider and playback improvements, including the Jellyfin release
  line and its release candidates.
- `1.2.x`: continued media-server, path, playback, and installation evolution.
- `1.3.x`: further integration, device, and playback reliability work.
- `1.4.x`: Home Assistant integration, diagnostics, media-track selection,
  telemetry controls, and OPPO playback/path reliability improvements.

The detailed version records and complete historical release notes are the
authoritative public account of those changes.
